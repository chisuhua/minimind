## 一、 激活参数 1B 小模型技术方向索引

针对激活参数在 **1B 左右**的小模型,提升推理能力不能仅依赖单一维度的优化,而需要构建一个覆盖"数据-训练-架构-推理-系统"的全栈技术图谱。以下是用户原始提出的所有可能的技术方向。

### 一、 数据工程:高质量推理信号的注入

对于 1B 模型,数据的"信噪比"比"规模"更重要。此方向旨在解决小模型学不到正确推理范式的问题。

| 细分方向 | 核心技术/关键词 | 调研重点与价值 |
| :--- | :--- | :--- |
| **认知对齐数据合成** | CogPO, CRV (Critique-Reflect-Verify), Cognitive Alignment | 解决大模型 CoT 对小模型"过难"的问题。调研如何根据小模型认知水平裁剪/改写推理链。 |
| **正负路径对比学习** | MRPV (Multi-path Reasoning), ReaLM, Contrastive CoT | 不仅学正确答案,还从错误路径中学习"为什么错"。调研样本构造与对比损失设计。 |
| **自我增强与自举** | Self-AMPLIFY, Self-Play, Bootstrapping | 无需外部教师,利用模型自身生成+验证能力迭代数据。调研小模型自举的崩溃边界与防退化机制。 |
| **结构化合成数据** | TinyStories, AS-ES (Abstract-Specific Split), Guided Distillation | 将逻辑与事实解耦,或注入领域规则。调研合成数据的多样性控制与质量过滤指标。 |
| **过程奖励建模数据** | PRM Data, Step-level Annotation, OmegaPRM | 为 RL 提供细粒度监督信号。调研如何低成本获取步骤级标注(如用大模型打分+人工校验)。 |

### 二、 训练策略:参数高效与认知适配

此方向旨在解决全量微调易过拟合、直接蒸馏效果差的核心矛盾。

| 细分方向 | 核心技术/关键词 | 调研重点与价值 |
| :--- | :--- | :--- |
| **参数高效强化学习** | Tina, LoRA-RL, PEFT for RLHF | 仅更新 <1% 参数实现越级性能。调研 LoRA 秩的选择、三阶段训练流程及动态奖励对齐。 |
| **认知偏好优化** | CogPO, DPO/KTO for SLMs | 替代传统 RLHF,直接对齐小模型认知轨迹。调研偏好对的构造方式及与小模型容量的匹配度。 |
| **回忆扩展动力学** | RED (Recall-Extend Dynamics), Dynamic Policy Shift | 平衡离线蒸馏与在线探索。调研熵变监控指标与策略转移阈值的设定。 |
| **渐进式课程学习** | Curriculum RL, Difficulty Scheduling | 从简单推理逐步过渡到复杂任务。调研难度度量标准与小模型学习曲线的关系。 |
| **混合蒸馏范式** | Hybrid Distillation (CoT+PoT), Counterfactual Distillation | 融合多种推理模式或多视角知识。调研不同推理范式的配比与协同效应。 |

### 三、 架构创新:以结构换容量

通过修改模型结构,在不增加激活参数的前提下提升等效推理深度或专家容量。

| 细分方向 | 核心技术/关键词 | 调研重点与价值 |
| :--- | :--- | :--- |
| **层间循环反馈** | Universal Transformer, mHC (Hyper-Connections), DeltaNet | 深层输出残差接入浅层,复用计算图。调研训练稳定性、自适应退出机制及与预训练权重的兼容方案。 |
| **MoE 升级/改造** | MoE Upcycling, Marco-Mini, Expert Routing | Dense 转 MoE 或原生 MoE 设计。调研 Upcycling 成本、专家数量/激活比例对 1B 模型的影响。 |
| **线性注意力/SSM** | RWKV, Mamba, Gated DeltaNet | 降低长上下文推理开销,支持更长思维链。调研在推理任务上与 Transformer 的性能差距及弥补方法。 |
| **神经符号混合架构** | Neuro-Symbolic, LLM+Solver, Code-as-Reasoner | 理解靠模型,计算靠外部求解器。调研接口设计、符号 grounding 及端到端训练可行性。 |
| **测试时自适应** | TTT (Test-Time Training), Fast Weights | 推理时即时更新部分参数以适应新任务。调研更新规则、计算开销及与缓存机制的冲突。 |

### 四、 推理时扩展:动态计算分配

在部署阶段通过策略换取性能,是小模型突破能力天花板的关键杠杆。

| 细分方向 | 核心技术/关键词 | 调研重点与价值 |
| :--- | :--- | :--- |
| **置信度驱动调度** | CDRL, CA-TTS, Uncertainty Quantification | 低置信度触发重思/求助,高置信度直出。调研置信度校准方法及与推理延迟的权衡。 |
| **自反思检索增强** | Self-RAG, Adaptive-RAG, Reflection Tokens | 按需检索+自我批判。调研反思 Token 的训练、检索决策的 RL 优化及噪声抑制。 |
| **智能体多轮循环** | Agent Loop, ReAct, Tool Use SFT | 用外部工具调用替代内部长链思考。调研工具调用准确率提升、结果回填规范及人机协作架构。 |
| **动态专家搜索** | DES (Dynamic Expert Search), Test-Time Scaling | MoE 模型运行时动态调整激活专家数。调研验证模型的设计及计算成本上限控制。 |
| **推测解码/大小协作** | R-Stitch, Speculative Decoding, Draft-and-Verify | 小模型草稿+大模型校验,或基于熵的风险路由。调研一致性衡量指标及无缝切换机制。 |
| **验证与修正循环** | CoVe, Self-Correction, Best-of-N | 生成后独立验证并修正。调研验证问题的自动生成质量及修正成功率。 |

### 五、 系统与部署优化:确保能力可用

使上述技术在资源受限设备上真正落地。

| 细分方向 | 核心技术/关键词 | 调研重点与价值 |
| :--- | :--- | :--- |
| **激活感知量化** | AWQ, SmoothQuant, INT4/FP8 | 保护关键权重,为运行时扩展腾出内存/算力。调研量化对推理能力的损伤及补偿微调。 |
| **异构计算调度** | PowerInfer-2, mllm-NPU, CPU-GPU Offloading | 充分利用端侧 NPU/CPU。调研算子拆分策略及通信开销优化。 |
| **KV Cache 管理** | PagedAttention, Sparse Attention, Cache Eviction | 维持长上下文推理速度。调研驱逐策略对推理连贯性的影响。 |
| **编译器与运行时加速** | ONNX Runtime, TensorRT-LLM, vLLM | 底层推理引擎优化。调研对不同架构(MoE/SSM/循环)的支持程度。 |

### 💡 调研执行建议(用户原版)

1. **建立基准线**:先选定 1-2 个 1B 基座模型(如 Qwen2.5-1.5B, SmolLM-1.7B)和标准评测集(GSM8K, ARC-C, BBH),所有调研均以相对提升为衡量标准。
2. **分层验证**:优先调研**数据工程**和**训练策略**(成本低、收益确定),再探索**推理时扩展**(工程价值高),最后考虑**架构创新**(风险高、周期长)。
3. **关注"失败案例"**:小模型不是大模型的缩小版。调研时特别留意论文中提到的"在小模型上无效"的方法及其原因分析,这比成功案例更有指导意义。
4. **追踪开源复现**:优先选择有开源代码/权重的方向进行 hands-on 证。推荐关注 HuggingFace Open-R1、TinyZero、Marco-Mini 等开源项目作为调研起点。
5. **构建技术矩阵**:将上述五个维度交叉组合(如"CogPO + Self-RAG + AWQ"),评估协同效应与兼容性,避免孤立看待单一技术。

## 二、 "Cog-Tina-RAG-Loop" 黄金组合(用户原版推荐)

> **以下为用户原文推荐,未经修正。基于综合调研报告的修正版本请见 `20-revised-proposal.md`**

基于"认知对齐优先、运行时换性能、系统兜底"的原则,推荐以下这套经过验证的 **"黄金组合"**。该组合兼顾了落地可行性与推理能力的上限突破。

### 🏆 推荐组合:Cog-Tina-RAG-Loop 全栈方案

| 层级 | 核心技术选型 | 替代/备选方案 | 选择理由(针对 1B 模型) |
| :--- | :--- | :--- | :--- |
| **数据层** | **CRV + CogPO 合成数据** | Self-AMPLIFY, MRPV | 解决大模型 CoT 对小模型"过难"问题;CRV 提供结构化反思信号,CogPO 确保数据与小模型认知轨迹对齐,避免无效蒸馏。 |
| **训练层** | **Tina (LoRA-RL) 三阶段** | 全量 SFT, DPO | 仅更新 <1% 参数,规避 1B 模型全量微调的灾难性遗忘;三阶段(SFT→RL→动态奖励)已在 Qwen2.5-0.5B 上验证越级性能。 |
| **架构层** | **mHC (Hyper-Connections)** | Universal Transformer, MoE Upcycling | 无需重构模型,即插即用实现深→浅反馈;流形约束保证训练稳定;相比 MoE 改造成本低一个数量级,适合 Dense 1B 模型。 |
| **推理层** | **Self-RAG + CA-TTS** | Agent Loop, DES | Self-RAG 解决事实性,CA-TTS 解决可靠性;两者共享置信度信号,形成"检索-反思-校准"闭环;比纯 Agent 循环延迟更低,更适合端侧。 |
| **系统层** | **AWQ INT4 + vLLM** | SmoothQuant, ONNX Runtime | AWQ 保护关键推理权重;vLLM 原生支持 PagedAttention+投机解码;为 Self-RAG 和 mHC 的额外计算腾出显存/算力预算。 |

### 🔍 组合协同效应解析(用户原版)

这套组合并非简单拼接,而是存在强耦合的正向反馈:

1. **数据→训练协同**:CRV 生成的带反思标签数据,直接作为 Tina 第一阶段 SFT 的语料;CogPO 的对齐目标函数,无缝衔接 Tina 第二阶段的 RL 优化目标,避免数据与训练目标割裂。
2. **训练→架构协同**:mHC 的跨层连接矩阵可通过 LoRA 适配器学习,与 Tina 的参数高效范式天然兼容;无需单独预训练循环模块,大幅降低架构创新的试错成本。
3. **推理→系统协同**:Self-RAG 的反思 Token 触发重生成时,CA-TTS 的置信度信号可直接复用 KV Cache 中的注意力分数,避免重复计算;AWQ 量化后的模型仍保留足够的精度余量支撑 mHC 的细粒度跨层信号传播。
4. **端到端闭环**:当 CA-TTS 检测到续低置信度时,可自动降级为"拒绝回答"或"转人工",防止 Self-RAG 陷入无效检索循环;这种安全兜底机制对 1B 模型在生产环境落地至关重要。

### ⚠️ 实施路线图与风险预警(用户原版)

#### 阶段一:基线建立与数据准备(2-3 周)
-   选定基座:Qwen2.5-1.5B-Instruct 或 SmolLM-1.7B
-   构建 CRV 数据管线:用 7B+ 教师模型生成带 `[Retrieve]`/`[IsRel]`/`[Revise]` 标签的 CoT 数据,经 CogPO 过滤后保留 5K-10K 高质量样本
-   **风险点**:小模型对反思 Token 的理解不稳定 → 对策:初期混入 30% 无标签标准 CoT 数据做 warmup

#### 阶段二:Tina+mHC 联合训练(3-4 周)
-   插入 mHC 模块(仅初始化连接矩阵),冻结基座权重
-   执行 Tina 三阶段:SFT(CRV 数据) → RL(GRPO+过程奖励) → 动态奖励对齐
-   **风险点**:mHC 导致梯度震荡 → 对策:启用渐进残差预热,前 20% 训练步长内将 mHC 权重从 0 线性增至 1

#### 阶段三:推理集成与量化(2 周)
-   部署 Self-RAG 逻辑:解析反思 Token 触发检索/重生成
-   集成 CA-TTS:基于 token 熵+自一致性投票计算置信度,设定动态阈值
-   AWQ INT4 量化 + vLLM 部署
-   **风险点**:量化后反思 Token 准确率下降 → 对策:量化感知微调,在 INT4 模拟环境下对 mHC 和 LoRA 适配器做 1 epoch 校准

#### 阶段四:评测与迭代(持续)
-   核心指标:GSM8K/ARC-C 准确率、检索 Precision@3、平均推理延迟、拒答率
-   **关键验收标准**:相比基线,推理准确率提升 ≥15%,P99 延迟增加 ≤30%,拒答误杀率 <5%

### 💡 何时虑替换组件?(用户原版)

-   **若模型为 MoE 架构**:将 mHC 替换为 **DES (Dynamic Expert Search)**,利用 MoE 天然优势实现测试时扩展,收益更高。
-   **若任务强依赖工具调用**:将 Self-RAG 替换为 **标准化 Agent Loop + Tool Use SFT**,但需额外投入工具调用数据的构造与验证。
-   **若端侧算力极度受限(<5 TOPS)**:将 CA-TTS 简化为 **固定阈值+早退机制**,牺牲部分可靠性换取确定性延迟;或将 vLLM 替换为 **llama.cpp + CPU-NPU 异构调度**。
-   **若需处理超长上下文(>32K)**:将 mHC 替换为 **Gated DeltaNet**,避免跨层连接在长序列下的内存爆炸问题。

> **最终建议**:此组合是当前 1B 模型推理能力提升的"最大公约数"方案,平衡了学术前沿性与工程落地性。建议先以最小可行产品形态跑通全流程,再根据实际瓶颈定向替换组件。切忌在未验证数据-训练协同效应前,盲目引入多个推理时扩展技术,否则极易陷入"调参地狱"。

## 三、 CRV 认知轨迹 + 循环深度模型方案(用户原版)

> **以下为用户原文方案,未经修正。基于综合调研报告的独立核查见 `05-loop-model-deepdive.md`,关键性结论为"概念混杂、未经验证、应被拒绝"**

将 CRV(批判-反思-验证)认知轨迹与循环深度模型(Looped Language Models / Depth-recurrent LLMs)结合,是目前前沿 AI 研究中极具潜力的方向。这种结合旨在让小模型无需生成大量"思考 Token",而是通过**在连续的潜在空间(Latent Space)中进行隐式循环计算**来实现长推理。

针对带有循环深度的小模型构造训练数据,核心逻辑必须从传统的"显式语言化步骤"转变为"基于答案的隐式状态演化"。以下是具体的数据构造策略:

### 1. 预训练阶段:"无中间步骤"的海量语料喂养

对于循环深度模型而言,预训练阶段的"答案"并非传统意义上的问答对标准答案,而是**下一个词预测(Next Token Prediction)** 的监督信号。
-   **数据形态**:不需要人工标注"第一步、第二步"的 CoT 过程,直接使用互联网原始文本(网页、代码、论文等)。
-   **内在机制**:模型被强制要求在不写出中间推导的情况下,仅依靠隐藏状态的反复更新(循环迭代)来"悟出"上下文逻辑。例如面对残缺句子,模型通过在向量空间中旋转形状进行数值或逻辑映射,直接预测最高概率的下一个词。
-   **数据规模要求极高**:因为模型需要自己琢磨"心算口诀"而非照着抄写步骤,这极度依赖海量数据进行试错和统计规律学习。研究表明,类似 Ouro 这样的 2.6B 小模型,可能需要消耗高达 7.7 万亿 Token 的数据才能达到媲美大模型的推理效果。

### 2. 后训练/微调阶段:利用循环 Transformer 合成高质量 CRV 种子

由于自回归模型在生成长而正确的思维链时容易出错,可以利用**循环 Transformer(Looped Transformer)具备的长度泛化能力**来反向赋能:
-   **RELAY 框架思路**:首先训练一个带有显式 CoT 对齐的循环模型。由于它能在单次循环迭代中处理更复杂的逻辑,它可以为超出常规训练长度的复杂问题,生成极其精确且可靠的推理链(CoT chains)。
-   **数据增强**:将这些由循环模型生成的超长、高质量推理链作为种子数据,合并到原始数据集中,用于微调自回归模型或进一步指导循环模型的潜在推理。

### 3. CRV 多智能体系统的认知对齐过滤

在构造包含"批判-重思-验证"结构的微调数据时,必须确保数据适配小模型的认知轨迹,避免大模型蒸馏带来的"水土不服":
-   **专属 CRV 系统**:构建多个 LLM 代理,分别负责根据小模型的认知能力去"批判"初始推理理由,基于批判结果"重思"改进,并"验证"最终正确性。
-   **CogPO 算法引入**:结合认知偏好优化(Cognitive Preference Optimization),将推理过程与小模型的实际知能力严格对齐,持续增强其推理能力,防止小模型盲目模仿大模型的冗长废话。

### 4. 内部神经电路的结构化诊断与纠错

为了让小模型的隐式循环推理更加可靠,可以借鉴 Meta 提出的 CRV(可解释性诊断)技术理念,将数据构造与模型内部结构挂钩:
-   **透视思维轨迹**:通过将 MLP 模块替换为 Transcoder 层,为模型安装"透视皮肤"。在推理过程中,提取节点数量、图密度等拓扑特征,绘制出动态变化的归因图(Attribution Graph)。
-   **结构化数据清洗**:如果合成的 CRV 数据在输入小模型后,导致内部生成的电路图出现纠缠、分布混乱或路径打结,说明该条数据的逻辑超出了小模型的认知负荷。这类数据应被自动识别为负样本或直接剔除,从而保证训练集的高效性。

**总结**:构造此类数据的核心在于**"外静内动"**——表面上摒弃了繁琐的自然语言中间步骤以节省算力,但在底层需要通过天文数字级的预训练语料、循环模型的高质量合成链条,以及严格的认知对齐过滤,来支撑起模型在潜在空间中的隐式深度思考。
